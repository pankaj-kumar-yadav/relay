# Self-host pack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One-command Docker Compose bring-up of web, API, and Postgres, with production env documented.

**Architecture:** Multi-stage Dockerfiles (repo-root context). API image runs `prisma migrate deploy` then `node dist/index.js`. Web image is Next standalone, browser calls published API at `NEXT_PUBLIC_API_URL`. Local compose uses `NODE_ENV=development` so invite URLs log to the API container.

**Tech Stack:** Docker Compose, Node 22 Alpine, pnpm 10.27.0, Prisma migrate deploy, Next.js standalone

**Spec:** [docs/superpowers/v1/September-2026/specs/2026-09-08-self-host-design.md](../specs/2026-09-08-self-host-design.md)

## Global Constraints

- Stay inside [SCOPE-V1.md](../../../../SCOPE-V1.md) — no billing, SSO, AI, or realtime
- Do not delete Circle files; do not change `apps/web/mock-data/**`
- Path aliases `@/` in API and web
- `NODE_ENV` is only `development` or `production`
- Do not commit unless the user explicitly asks
- Do not seed on compose up

### Task 1: API production build

**Files:**
- Modify: `apps/api/package.json`
- Create: `apps/api/scripts/copy-generated.mjs`

- [ ] **Step 1: Add copy script and npm scripts**

`apps/api/scripts/copy-generated.mjs`:

```js
import { cpSync } from 'node:fs';

cpSync('src/generated', 'dist/generated', { recursive: true });
```

In `apps/api/package.json` scripts:

```json
"build": "prisma generate && tsc -p tsconfig.json && tsc-alias -p tsconfig.json && node scripts/copy-generated.mjs",
"start": "node dist/index.js",
"db:migrate:deploy": "prisma migrate deploy"
```

- [ ] **Step 2: Run the API build**

Run: `pnpm --filter @relay/api build`
